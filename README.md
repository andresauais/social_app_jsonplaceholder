# Social App JSONPlaceholder

Aplicación frontend construida con **Vite + React + TypeScript**, que consume la API de [JSONPlaceholder](https://jsonplaceholder.typicode.com). Permite visualizar información de usuarios, álbumes, fotos y gestionar TODOs.

## 🚀 Funcionalidades

- Consulta de detalles de usuario
- Visualización de álbumes y fotos
- Gestión de TODOs (añadir, editar, eliminar, validar sin números)
- Navegación por rutas con React Router
- Gestión de datos con React Query
- Tests unitarios y de integración con Vitest
- Dockerizado para despliegue sencillo

## 📦 Instalación local
```bash
npm install
npm run dev
```

## 🧪 Ejecutar tests
```bash
npm run test
```

## 🐳 Usar con Docker
```bash
docker compose up --build
```
